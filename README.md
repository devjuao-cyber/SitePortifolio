# 🚀 Portfólio Profissional

Um site de portfólio desenvolvido para apresentar meus projetos, compartilhar minhas experiências e demonstrar minhas habilidades por meio de aplicações reais.

O projeto foi construído utilizando **HTML5, CSS3 e JavaScript Vanilla**, priorizando performance, leveza, organização e uma experiência de navegação intuitiva.

## 📌 Sobre o projeto

Este portfólio foi desenvolvido com o objetivo de centralizar minha apresentação profissional e meus projeto alem do meu laboratorio de pesquisa em um único ambiente, permitindo que visitantes conheçam meu trabalho, explorem minhas aplicações e tenham acesso aos respectivos repositórios.

A proposta vai além de simplesmente exibir projetos: cada trabalho possui uma página de demonstração própria, onde apresento detalhes sobre seu desenvolvimento, funcionalidades e objetivos, acompanhados de um vídeo explicativo.

## ✨ Funcionalidades

### 🏠 Página inicial

- Apresentação e resumo sobre mim.
- Exibição de projetos selecionados em destaque.
- Acesso rápido aos meus principais canais de contato.
- Navegação intuitiva para explorar outras áreas do portfólio.

### 🗂️ Galeria de projetos

- Página dedicada à apresentação dos projetos desenvolvidos.
- Organização dos projetos em cards individuais.
- Acesso à demonstração detalhada de cada projeto.
- Link direto para o respectivo repositório no GitHub.

### 🔍 Página de demonstração dos projetos

Cada projeto possui uma página dedicada com:

- Vídeo explicativo apresentando o projeto.
- Descrição detalhada da aplicação.
- Apresentação de seus objetivos e funcionalidades.
- Informações que contextualizam o desenvolvimento.
- Acesso ao repositório no GitHub.
- Canais de contato.

### 📬 Contato

Disponibilização de canais de comunicação para facilitar o contato de recrutadores, profissionais e clientes interessados no meu trabalho.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação e semântica das páginas |
| CSS3 | Estilização, layout e responsividade |
| JavaScript Vanilla | Interatividade e funcionalidades |

### Por que JavaScript Vanilla?

A escolha do JavaScript puro foi uma decisão técnica para manter o projeto leve, reduzir dependências externas e evitar a complexidade desnecessária de frameworks para uma aplicação com essa finalidade.

O objetivo foi construir uma experiência eficiente, com carregamento otimizado e controle direto sobre a implementação.

## 🧭 Experiência de navegação

O fluxo de navegação foi pensado para facilitar a descoberta dos projetos:

1. O visitante acessa a página inicial e conhece minha apresentação profissional.
2. Visualiza alguns projetos selecionados na seção de destaques.
3. Pode acessar a galeria para explorar outros trabalhos.
4. Seleciona um projeto por meio do botão **Demo** para conhecer sua apresentação detalhada.
5. Na página do projeto, pode assistir ao vídeo explicativo e conhecer suas funcionalidades.
6. Caso queira analisar a implementação, pode acessar o código-fonte pelo botão **GitHub**.

## ⚡ Performance e decisões técnicas

O desenvolvimento priorizou uma estrutura simples e eficiente, utilizando tecnologias nativas da web.

Principais diretrizes:

- Utilização de HTML semântico.
- CSS para construção e organização dos layouts.
- JavaScript Vanilla para implementar as interações.
- Redução de dependências externas.
- Priorização de uma estrutura leve e de fácil manutenção.
- Organização da experiência de navegação entre as páginas.
